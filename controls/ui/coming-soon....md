### Variants <a href="#variants" id="variants"></a>

Use the variant prop to change the visual style of the button.

{% hint style="info" %}
Use primary buttons sparingly, mostly for form submissions.
{% endhint %}

### Themes

* Primary
* Secondary
* Accent
* Success
* Info
* Warning
* Error

### Styles

* Gradient
* Solid
* Outline
* Ghost (No Bg and Border)
